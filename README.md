# ICP Bulgaria 🇧🇬

Добре дошли в проекта **ICP Bulgaria**! Ние сме общност, обединена около Internet Computer (ICP) технологията. Нашата цел е да експериментираме и изградим DAO (децентрализирана автономна организация) приложение, което да позволява гласуване и автономно управление на социални цели. Чрез използването на ICP, хостваме нашето приложение и смарт контракти (Canisters), за да създадем напълно децентрализирано и прозрачно решение.

## Цели на проекта

- Да експериментираме с инструменти на ICP мрежата.
- Да изградим DAO приложение за гласуване на различни въпроси.
- Да създадем децентрализирано социално приложение, което автономно постига своите цели.
  
## Използвани технологии

- **Internet Computer (ICP)**: Платформа за хостване на Web интерфейса и смарт контрактите.
- **dfx**: Основният инструмент за разработка в ICP мрежата.
- **npm**: Управление на зависимости и стартиране на проекта.

## Инсталация

За да стартирате проекта локално, следвайте стъпките по-долу:

1. **Клониране на репозитория**:
    ```bash
    git clone https://github.com/your-repo/icp-bulgaria.git
    cd icp-bulgaria
    ```

2. **Инсталиране на зависимости**:
    Уверете се, че имате инсталирани **npm** и **dfx**. Ако не са налични, следвайте инструкциите за инсталация на официалните им сайтове.

    > **Важно**: Влезте в директорията `src/web_interface` и инсталирайте всички зависимости на фронтенда, като изпълните следната команда:
    ```bash
    npm install
    ```

## Стартиране на проекта

За да стартирате локалната среда за разработка, изпълнете следните стъпки:

1. **Стартиране на локалната ICP мрежа**:
    ```bash
    dfx start
    ```

2. **Стартиране на ICP Ledger репликата**:
    ```bash
    sh ./scripts/setup_local_icp_ledger.sh
    ```

3. **Деплой на смарт контрактите (Canisters)**:
    ```bash
    dfx deploy
    ```

4. **Стартиране на уеб интерфейса**:
    ```bash
    npm run dev
    ```

Проектът ще бъде достъпен на локалния адрес: [http://localhost:3000](http://localhost:3000)
